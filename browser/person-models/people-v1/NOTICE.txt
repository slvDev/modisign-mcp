Modisign people-v1 segmentation assets
======================================

Modisign Studio can place a title behind the people in a footage clip. It does
this on the device with a small person-segmentation model and the MediaPipe
Tasks Vision runtime. Both are third-party works under the Apache License,
Version 2.0 (licenses/Apache-2.0.txt). Nothing here is a Modisign design.
The model, the wasm and the loader files are distributed without modification.
person-worker.js is Modisign code that bundles the runtime's JavaScript API. The
probe image is a downscaled frame of a public-domain video. This file and licenses/ accompany
the model on the website and, as a copy, the runtime files under
/person-runtime/0.10.21/. Every other place Modisign distributes these files
(such as the MCP npm package) carries the same file and folder.

Using these files
-----------------

These files are served to the browser so the model runs on the device. The
footage never leaves it. The Apache-2.0 grants are separate from Modisign's own
terms for exports and from the rights a user has in their footage.
