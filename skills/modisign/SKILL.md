---
name: modisign
description: Find and render Modisign animated overlays, or create a finished local Studio video with split screen, cuts, captions, transitions, layer motion, sound effects and overlays through MCP.
---

Use for animated hooks, subscribe/follow buttons, lower thirds and CTAs. Rendering runs locally; Modisign receives overlay settings and chosen text, never footage.

1. Call `account_status`. Prefer unchanged free presets when the user has not asked for customization. Free needs no login; custom text, looks, colors or Pro presets require current Pro. Aspect and output/background changes remain free.
2. Call `list_overlays` with relevant search/filter options, then `get_overlay` for the chosen result. Never invent family/preset IDs, looks or fields; use the returned schema and limits. A field with `relevant: false` is not used by the preset’s current layout: switch the layout/option named in its `showWhen` first, or leave it alone.
3. Call `configure_overlay`, including only requested edits. Check the returned tier before rendering, and the `inactiveEdits`/`notice` for values the chosen layout does not use. If Pro is needed, explain why and offer an unchanged free option or https://modisign.app/pricing. Use `login` when the user chooses to sign in; show its approval link/code, then check `account_status`. Never ask for passwords or tokens.
4. Call `render_overlay` for standalone MP4 (green screen by default), transparent ProRes MOV or VP9 WebM. For a composite, ask for the video's local path when missing, resolve it to an absolute path, then call `add_overlay_to_video` with the requested start in seconds. Videos must be at most 60 seconds. Respect the returned start limit and chosen overlay aspect; composites preserve the video's aspect, cap the long side at 1920 and include its audio.
5. For multi-clip edits, optionally call `get_transcript` first when the user wants to review or fix speech; explain that its transcript text is returned to the assistant/provider. Then call `edit_video` with absolute clip paths, requested trims, settings, transitions, pause removal, configured overlays and captions. Every clip requires `track: "v1"` or `"v2"`. V1 plays in request order and forbids `start`; V2 requires nonnegative timeline `start` seconds and forbids overlap with other V2 clips. `after_clip` is a zero-based request-array index of a V1 clip; the next V1 is its transition neighbor, skipping V2. Punch-ins use source seconds. Optional `crop` removes top/right/bottom/left source percentages (0–95, opposite edges sum to at most 95); omission means zero crop. Optional `place` uses `{mode}` for full/top/bottom/left/right or pip-top-left/pip-top-right/pip-bottom-left/pip-bottom-right, or `{mode:"custom",x,y,width,height}` normalized inside the output (minimum dimensions 0.05); omission means full. Captions and pause detection use V1 only, even if muted. Pause removal cuts and ripples both tracks and overlays together; report the explicit V1 transition conflict and remove that transition only if the user requests it. Align sources manually; there is no automatic sync/drift correction. Include caption style, position and size and any agreed `corrections: [{from, to}]`. Studio supports 180 seconds, video and JPEG/PNG/WebP/AVIF photos, and free 1080p/720p. No overlays or unchanged free overlays with Clean/Boxed/Minimal captions need no account; expressive styles and Pro configurations need Pro. Studio exports never enter history.
6. For titles or a rapid intro, add `texts` (native titles, up to 100; each bound to a V1 or V2 clip with `clip`, optionally stamped `timestamp: "source"` for the clip's source in-point as mm:ss or `"timeline"`, or placed with `start` and `duration` seconds) and/or `rapid_intro: {clips, labels, frames_per_clip, timestamp, mute_teasers}` in the same `edit_video` call. `clips` are 5–7 unique V1 request indices in teaser order, `frames_per_clip` is 3–6 (default 5) and `labels` has exactly one `{clip, text}` per chosen clip. You cannot see the footage: ask the user what each clip shows, or use the descriptions they gave, and never invent labels or derive them from file names. Photos cannot use `source` stamps. Times for V2 clips, overlays and explicit titles move later by the intro length, so give them as for the edit without the intro. A clip must be at least as long as its teaser; the shortest any trim or photo can be is 3 frames (0.1 seconds). Plain titles and the rapid intro are free and never leave the computer. A title may take `reveal` (a rectangular wipe over stationary text) or `occlusion` (“put the title behind me”: behind the people in one clip, by its zero-based index in `clips`); the `texts` schema in the tool gives every field, default and rule. A title with a reveal or behind people needs Pro to export, so say so before adding one. If a field error names the cause (for example `texts.0.reveal.duration` or `texts.0.occlusion.clip`), correct it and retry; nothing is written on a refusal.
7. For motion (move, zoom, rotate or fade a layer over time), add `motion` to a clip, a title or an overlay request in the same `edit_video` call: `{x, y, scale, rotation, opacity}`, each an array of keys `{at, value, easing}` with strictly increasing `at`. Units: `x`/`y` are fractions of the output width/height (positive right and down, `-0.15` is 15% left), `scale` is a multiplier (`1.2` is 120%), `rotation` is clockwise degrees and `opacity` is 0–1. `zoom` is static inner framing of the picture; `motion.scale` is outer motion of the whole placed picture, so use `motion.scale` for animated zooms. Keys are in SOURCE seconds for footage (a photo's clock starts at its `in`, default 0) and in LOCAL seconds from its own start for titles and overlays. `easing` shapes the segment after its key: `hold`, `linear`, `ease-in`, `ease-out`, `ease-in-out` or a custom `[x1, y1, x2, y2]` curve with each number from 0 to 1; values hold before the first and after the last key. At most 60 keys per channel and 1000 per request. Vague requests (“zoom in a bit”) need stated choices of amount, start, end and target layer from the user or you; the tool has no hidden defaults. Footage and title motion are free. Any non-neutral motion key on a catalog overlay, even on a free preset, needs Pro; keys that all equal the neutral value stay free, so explain that before adding overlay motion and offer a motion-free overlay otherwise. Field errors name the path and reason (for example `clips.0.motion: Motion scale[1].value must be between 0.1 and 5.`); correct and retry.
8. For sound effects, add `sfx` (up to 100) and/or `auto_sfx` to the same `edit_video` call. The only sounds are the ten in the built-in free pack: click `ugc-click-01` (Interface click), `ugc-click-02` (Mouse click); typing `ugc-typing-01` (Keyboard burst), `ugc-typing-02` (Single mechanical key); whoosh `ugc-whoosh-01` (Bamboo swish), `ugc-whoosh-02` (Air sweep); pop `ugc-pop-01` (Bubble pop), `ugc-pop-02` (Mouth pop); sparkle `ugc-sparkle-01` (Cartoon sparkle), `ugc-sparkle-02` (Magic chime). Never accept or invent another source: there is no audio path, link, search, music, voice or generated sound. Each `sfx` row has `asset` and exactly one of `start` (seconds of the edit as the user describes it, before pause removal and any rapid intro, which move it with the edit) or `anchor`: `{kind:"title-enter", text}` (index in `texts`), `{kind:"transition", after_clip}` (request index of a V1 clip listed in `transitions`) or `{kind:"overlay-cue", overlay, cue}` (index in `overlays`; `cue` must be an id from that overlay's `activeCues` in `configure_overlay`, so call it first and tell the user when an overlay has none). Optional `offset` (-2 to 2 seconds, anchors only), `in`/`out` (seconds inside the sound), `gain` (0-2; the default is the sound's own quiet level, so keep it unless asked), `mute`, `fade_in`, `fade_out`. `auto_sfx: {events, seed, intensity, title_sound}` places one sound per title appearance, configured transition (not hard cuts) and declared overlay tap on the finished edit; the job `warnings` list what was added and skipped, so relay them. Sounds are free, play alongside the clips without changing speech volume or the video's length, and the request never leaves the computer.
9. Poll `job_status` until completion, failure or cancellation. Report the finished path and any warnings; do not announce success from a queued response. Use `cancel_job` if the user stops it.

Example: “Make a five-frame rapid intro from grind.mp4, pour.mp4, stir.mp4, steam.mp4 and serve.mp4, then replay them with source timestamps and the labels “Grind beans”, “Pour water”, “Stir”, “Steam milk” and “Serve”, in 9:16.” (the user supplied the labels) is one `edit_video` call with five V1 clips, `"rapid_intro": {"clips":[0,1,2,3,4],"frames_per_clip":5,"timestamp":"source","labels":[{"clip":0,"text":"Grind beans"},{"clip":1,"text":"Pour water"},{"clip":2,"text":"Stir"},{"clip":3,"text":"Steam milk"},{"clip":4,"text":"Serve"}]}` and `"aspect":"9x16"`.

Example: “Add a quiet interface click at 1.2 seconds and a bubble pop when the title “My three tips” appears; keep the clip's speech volume unchanged.” is one `edit_video` call: `"texts": [{"text":"My three tips","start":0.8,"duration":2}]`, `"sfx": [{"asset":"ugc-click-01","start":1.2,"gain":0.25},{"asset":"ugc-pop-01","anchor":{"kind":"title-enter","text":0}}]`. “Add subtle whooshes at my crossfades and clicks at declared overlay taps, using different variants; tell me which overlays have no tap cue.” is `"auto_sfx": {"events":["transition","cta-tap"],"intensity":"subtle"}` (and, if the user asks for a particular variant, explicit `sfx` rows), then relay the skipped overlays from the job warnings.

Example: “On the first clip, smoothly zoom from 100% at source 0s to 120% at 2s, then slide 15% left by 3s; fade ‘Watch this’ in over its first half-second, in 9:16.” is one `edit_video` call:

```json
{
  "clips": [{
    "path": "/absolute/clip.mp4", "track": "v1", "in": 0, "out": 4,
    "motion": {
      "scale": [{"at":0,"value":1,"easing":"ease-in-out"}, {"at":2,"value":1.2,"easing":"linear"}],
      "x": [{"at":0,"value":0,"easing":"hold"}, {"at":2,"value":0,"easing":"ease-in-out"}, {"at":3,"value":-0.15,"easing":"linear"}]
    }
  }],
  "texts": [{
    "text": "Watch this", "start": 0, "duration": 4,
    "motion": {"opacity": [{"at":0,"value":0,"easing":"ease-out"}, {"at":0.5,"value":1,"easing":"linear"}]}
  }],
  "aspect": "9x16"
}
```

Example: “Put reference.mp4 on top, muted, me.mp4 on the bottom, crop 5% off the sides, start them together, Clean captions from my voice.” Call `edit_video` with:

```json
{
  "clips": [
    {"path":"/absolute/me.mp4","track":"v1","in":0,"out":6,"place":{"mode":"bottom"},"crop":{"top":0,"right":5,"bottom":0,"left":5}},
    {"path":"/absolute/reference.mp4","track":"v2","start":0,"in":0,"out":6,"place":{"mode":"top"},"crop":{"top":0,"right":5,"bottom":0,"left":5},"mute":true}
  ],
  "aspect": "9x16",
  "captions": {"style":"clean","position":"lower","size":"m"}
}
```

Node 22+, FFmpeg and ffprobe on PATH are required. On an FFmpeg error, offer the returned installation command and retry once installed. The first render may report `downloading_browser` while downloading a private render browser (about 100 MB); keep polling. A title behind people reports `preparing_people_model` and `preparing_people_masks` while the bundled people model starts and masks are made; keep polling. Captions report `downloading_speech_model` on the first run and `preparing_captions` while speech is transcribed; keep polling. Linux ARM64 requires Chromium. If setup fails, run `npx -y @modisign/mcp doctor` when shell tools are available and follow its diagnosis; do not invent another browser installer.

Default outputs go to `~/Movies/Modisign` on macOS and `~/Videos/Modisign` elsewhere. Custom output paths must be absolute. Existing files are preserved with numbered suffixes. Jobs last only for this server process; successful Pro configurations attempt account history, while a history warning never removes the local file.
